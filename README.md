# Bureau Ingold — сайт

Статика: три файла, без сборки и зависимостей. Открывается двойным щелчком по `index.html`.

```
index.html      структура, весь текст, разметка JSON-LD
styles.css      палитра, типографика, сетка — всё настраиваемое в :root сверху
script.js       проявление блоков при прокрутке, состояние верхней строки
fonts/          четыре файла шрифтов, грузятся со своего домена
images/         портреты, 4:5, тонированы под палитру
legal/          три правовых документа: .md — исходники, .html — страницы сайта
robots.txt      доступ роботов, ссылка на sitemap
sitemap.xml     четыре адреса
llms.txt        описание практики для языковых систем
.nojekyll       пустой файл, отключает обработку Jekyll
```

Папку `fonts` заливать целиком. Без неё страница откроется системным шрифтом.

Имена файлов менять нельзя. Главная страница должна называться ровно `index.html` — браузер при скачивании иногда добавляет `(1)` или `(2)`, и тогда GitHub показывает README вместо сайта.

## Публикация на GitHub Pages

Репозиторий: `veronikaingolycheva/bureauingold.com`, публичный.

1. Все файлы лежат в корне репозитория, не в папке.
2. **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт открывается по адресу `https://veronikaingolycheva.github.io/bureauingold.com/`.

## Свой домен

Сначала GitHub, потом Cloudflare — в обратном порядке GitHub иногда сообщает, что домен занят.

**Settings → Pages → Custom domain** → вписать `bureauingold.com` → Save. В репозитории появится служебный файл `CNAME`; удалять его не нужно.

Затем в Cloudflare, в DNS зоны `bureauingold.com`:

| Тип | Имя | Content | Прокси |
|---|---|---|---|
| A | `@` | `185.199.108.153` | DNS only |
| A | `@` | `185.199.109.153` | DNS only |
| A | `@` | `185.199.110.153` | DNS only |
| A | `@` | `185.199.111.153` | DNS only |
| CNAME | `www` | `veronikaingolycheva.github.io` | DNS only |

Четыре A-записи — это адреса GitHub Pages для корня домена. Имя репозитория в записях не участвует.

Три места, где обычно ломается:

- **Прокси серый, DNS only.** С оранжевым облаком GitHub не выпустит сертификат. После того как в Pages станет активной галочка *Enforce HTTPS*, прокси можно включить обратно.
- **SSL/TLS → Overview** в режиме **Full**, не Flexible.
- Если Cloudflare создал для корня свою A-запись автоматически — удалить её перед добавлением этих.

Сертификат появляется обычно за десять минут, иногда в течение часа.

Почтовые записи Cloudflare Email Routing это не затрагивает: `hello@` и `veronika@` продолжают работать.

## Что менять чаще всего

**Палитра и ритм** — блок `:root` в начале `styles.css`.
`--air` задаёт вертикальный воздух между экранами: больше значение — просторнее.
`--measure` — ширина текстовой колонки.

**Шрифты** — строка `<link>` в `<head>` и переменные `--serif` / `--sans`.

**Цитаты-разделители** — блоки `.divider` в `index.html`. Их два; третий добавляется копированием.

**Отзывы** — раздел `#voices` лежит в `index.html` закомментированным. Включается снятием комментария вокруг `<section class="voices">` и пункта Voices в верхней строке. До появления настоящей фразы с полным именем, компанией и датой остаётся выключенным.

**Кейс** — когда появятся цифры, раздел `#work` заменяется на карточку кейса: исходная позиция, решения, результат.

**Портреты** — лежат в папке `images`, 900×1125, обесцвечены и тонированы под палитру. Если менять на новые: тот же кроп 4:5, то же тонирование, иначе два портрета перестанут читаться как одна серия.

**Аналитика** — Cloudflare Web Analytics подключена, токен вставлен в `index.html` и в три файла `legal/*.html`. Режим в панели Cloudflare: Enable with JS Snippet installation. Прокси остаётся серым, включать не нужно. Токен публичный: он виден в исходном коде любой страницы, доступа к аккаунту не даёт.

**Правовые страницы** пересобираются из markdown скриптом; если правишь `.md`, `.html` нужно перегенерировать, иначе они разойдутся.

**Роботы.** В `robots.txt` доступ открыт всем, включая роботов языковых систем — практика заинтересована в том, чтобы её описывали точно. Закрывается заменой `Allow: /` на `Disallow: /` у нужного робота.
